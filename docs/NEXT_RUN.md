**후보 B — 게이트 문턱.** `--gate`가 켜지면 자가대전 양쪽과 게이트 상대가 모두 `best.pt`이고, 현직은 55% 초과 때만 갱신된다(`train_loop.py` 400·479행). 승격이 없으면 루프는 계속 imitate8 데이터로 imitate8을 재학습한다 — **한 발짝도 움직이지 않는다.** 후보가 +3pp 나아져도 400게임의 ±5pp 안이면 문턱을 못 넘고 그 이득은 버려진다. curriculum4는 i0에 +13.5pp가 나와 한 번에 넘었기 때문에 굴러갔다.
→ **검증 방법**: `--gate-threshold 0.5`("지지 않으면 승격") 또는 `--gate 0`(AlphaZero식, 최신 망으로 자가대전).

## 5. 다음 실행 후보

**(1) 출발점 A/B — 추천.** v3와 비교해 바뀌는 변수가 출발점 하나뿐이다. 약 5.5시간 + 판정 25분.

```bash
python scripts/train_loop.py --init runs/imitate9/net.pt --iterations 8 \
  --battles 250 --search-iterations 800 --evaluate-every 2 --evaluate-battles 60 \
  --teams parties:43,14,42,10 --hidden 512 --blocks 4 --workers 10 \
  --bootstrap-weight 1 --root-noise 0.25 --sample-turns 12 --gate 200 --train-steps 256 \
  --learning-rate 3e-4 --out runs/curriculum_v4 --name curriculum_v4
```
i2 승격이면 후보 A 확인, 여기서도 i6이면 A는 무죄 → 후보 B로.

**(2) 게이트 문턱.** 위 명령에 `--gate-threshold 0.5`만 추가. 작은 이득이 누적되고 붕괴 방어는 유지된다.

**(3) 증류 보강.** 풀이 2.3배가 됐으니 `--battles`를 그만큼 늘려 imitate10. 90분. (1)·(2)가 답을 못 주면.

어느 쪽이든 끝나면:
